# ORFDS-Ocular-Retinal-Fundus-Disease-Screener
ORFDS is a multi-task deep learning system using MobileNetV2 to classify five retinal diseases: DR, Glaucoma, DME, AMD and HR. It integrates 16,392 images from multiple datasets, with CLAHE preprocessing and validity-aware masked loss, targeting FPGA-based Edge-AI deployment on the Kria KR260.
